# Object-Oriented Programming

Esercizi del percorso di laurea EPICODE dedicati alla programmazione a oggetti in Java.

Parte di [**EPICODE Bachelor**](../README.md), nella cartella `object-oriented-programming/`.

## Tecnologie

Java.

## Struttura e utilizzo

[`helloworld/`](helloworld/) contiene il primo programma Java; [`firsty/`](firsty/) contiene un esempio con classi e oggetti. Dalla radice della raccolta:

```sh
cd object-oriented-programming
javac helloworld/HelloWorld.java
java -cp helloworld HelloWorld
javac firsty/*.java
java firsty.Main
```

È richiesto un JDK disponibile nel terminale.
